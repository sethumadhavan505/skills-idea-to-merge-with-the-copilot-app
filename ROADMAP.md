# Mona's Bookmark Manager

A practical roadmap for making saved links easier to organize, update, and protect.

| Area | Item | Type | Priority |
|---|---|---|---|
| Discovery | Search & filter bookmarks | ✨ Feature | High |
| Bookmark management | Edit a bookmark | ✨ Feature | Medium |
| Organization | Tags or folders | ✨ Feature | Medium |
| Portability | Import & export bookmarks | ✨ Feature | Medium |
| Data integrity | Duplicate slugs on re-add | 🐛 Bug / risk | Medium |
| Validation | Empty-URL validation | 🐛 Bug / risk | High |
| Data safety | Bookmarks lost when localStorage is cleared | 🐛 Bug / risk | High |

## ✨ Planned features

- 🔎 Search & filter bookmarks — priority: high
- ✏️ Edit a bookmark — priority: medium
- 🏷️ Organize bookmarks with tags or folders — priority: medium
- 📦 Import and export bookmarks — priority: medium

## ⚠️ Known bugs & risks

- 🔁 Duplicate slugs can be created when a bookmark is re-added — priority: medium
- 🚫 Empty URLs may be accepted without validation — priority: high
- 🧹 Clearing localStorage can permanently remove saved bookmarks — priority: high
